# RCM PC Controller (`rcm-pc`)

Standalone cross-platform Discord remote controller and monitor for Windows, Linux, and macOS machines plus any Minecraft server/client instance.

## Quick Start

```bash
pip install .
rcm-pc init --token YOUR_DISCORD_BOT_TOKEN
rcm-pc run
```

Then run `/pc pair <code>` or `!pc pair <code>` in Discord using the 6-digit pairing code printed in your terminal!
